# Personal Mini-Toolkit

## Project Description

The Personal Mini-Toolkit is a beginner-friendly Python program that combines three useful interactive tools in one menu-driven application.

### Tools Included

1. **Simple Calculator:** Performs addition, subtraction, multiplication and division.
2. **Number Guessing Game:** Challenges users to guess a randomly generated number between 1 and 10 within five attempts.
3. **To-Do List:** Allows users to add, view and remove tasks.

## Concepts Practiced

- Variables and data types
- User input and output
- If, elif and else statements
- While loops and for loops
- Lists and list methods
- Functions
- F-strings
- Error handling
- Comments and code organization

## Project Files

- `toolkit_plan.txt` – The project planning document.
- `toolkit.py` – The main Python application.
- `screenshots/` – Screenshots showing the menu and all three tools.

## How to Run the Program

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or a terminal.
4. Run the following command:

```bash
python toolkit.py
```

5. Select a tool from the menu and follow the instructions.

## Project Reflection

The most challenging part of this project was designing the menu loop so that users could move between different tools without the program stopping unexpectedly. The part that required the most attention was handling user choices and making sure the program returned to the main menu correctly. I also had to ensure that the number guessing game counted attempts accurately. Testing the calculator helped me understand how conditionals can be used to perform different mathematical operations. Building the to-do list improved my understanding of Python lists and how to add and remove items dynamically. I enjoyed combining different Python concepts into one interactive application. With one more week, I would add more tools, improve the user interface and include an option to save tasks permanently.
